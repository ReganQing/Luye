# 绿野 Luye · Halo 2 主题

深绿玻璃拟态（Glassmorphism）风格的 [Halo 2](https://www.halo.run/) 博客主题。视觉语言移植自 Ron567 个人主页（[aboutme](https://github.com/ReganQing/aboutme)）：雾绿光晕背景、毛玻璃卡片、衬线大标题、胶囊按钮，以及标志性的晴 / 雨 / 雪 Canvas 粒子背景特效。

## 特性

- **深绿玻璃拟态设计**：`#0E1F17 → #08120E` 渐变底色 + 雾绿光晕 + `backdrop-filter` 毛玻璃卡片，与个人主页同源的设计令牌。
- **天气背景特效**：导航栏可切换晴（光柱与浮尘）/ 雨 / 雪三种 Canvas 粒子背景，选择持久化到浏览器本地，尊重 `prefers-reduced-motion`。
- **完整页面模板**：首页（Hero + 数据徽章 + 精选专题 + 混合布局文章列表 + 作者卡片）、文章页（玻璃正文面板 + 目录样式排版 + 上下篇 + 评论区）、独立页面、文章归档（时间线）、分类/标签页、作者页、404。
- **「关于我」自定义模板**：眉题 + 大标题 + 圆形玻璃头像徽章，复刻个人主页的 About 版式，在后台创建页面后可选用。
- **响应式**：桌面三栏卡片网格到移动端单列自适应，移动端抽屉式导航。
- **主题设置**：品牌副标题、Hero 文案与横幅图、主题强调色、页脚文案、字体加载开关等均可在后台配置。
- **控制台入口**：可在导航栏与页脚显示「控制台」按钮直达站点后台，也能一键关闭以避免暴露后台地址。
- **SEO**：页面独立标题、分页规范链接、Open Graph / Twitter Card 和可关闭的文章 BlogPosting 结构化数据；保留 Halo 自身的描述注入。

## 安装

要求 Halo ≥ 2.26.0（使用了该版本引入的 `layout.html` 页面布局契约）。

1. 将本目录打包为 zip：在 `theme-luye` 目录的**上一级**执行 `zip -r theme-luye.zip theme-luye`（确保 zip 内第一层是 `theme-luye` 文件夹）。
2. 进入 Halo 后台 → 外观 → 主题 → 安装主题，上传 zip。
3. 启用「绿野 Luye」，并在「主题设置」中按需调整后点击保存（修改设置后如未生效，点击「重载主题配置」）。

## 页面建议

- **导航菜单**：后台 → 外观 → 菜单，创建主菜单（首页 / 归档 / 分类 / 标签 / 关于）。
- **关于页**：新建独立页面（别名建议 `about`），在页面设置中将模板切换为「关于我」。
- **文章封面**：文章上传封面图后，首页置顶卡片与文章页头图会自动展示。

## 代码块高亮

主题保留普通代码块的深绿配色，语法高亮由 Halo 插件提供。可安装并启用 [highlight.js 代码高亮](https://github.com/halo-sigs/plugin-highlightjs) 或 [Shiki 代码高亮](https://github.com/halo-sigs/plugin-shiki)，同一时间启用一个即可。

- **highlight.js**：已高亮代码块的背景和文字颜色由插件主题接管，行内代码和未高亮代码块继续使用主题的绿色配色。
- **Shiki**：绿野是固定深色主题，页面通过 `data-color-scheme="dark"` 标记深色外观，插件会使用其配置的暗色高亮主题。
- **编辑器与前台一致**：主题不会自动同步编辑器配色。使用 Shiki 时，将插件的「编辑器设置 → 高亮主题」与「基本设置 → 暗色主题」设为同一配色；highlight.js 的前台配色在其插件设置中选择。

## SEO 配置

首页标题使用系统设置中的站点标题与副标题；文章、独立页面、分类、标签和作者页使用各自的名称。分页标题追加页码，分页 canonical 保留当前页；归档 canonical 同时保留年份和月份。

站点首页的 `description` 在 Halo「设置 → SEO 设置」维护；文章、页面摘要及分类、标签描述由对应内容管理。主题不会重复注入同名标签。站点的外部访问地址必须与实际域名一致，它用于生成绝对规范链接和分享图片地址。

升级后在主题详情中重载配置。在主题设置「SEO」中可以分别关闭页面元数据和文章结构化数据，避免与其他 SEO 插件重复输出。页面标题不受这两个开关影响。设置「基础 → 个人主页链接」后可建立博客与个人站点的互链。

发布后检查首页、文章、独立页、分类、标签、作者、按年月归档和第二页的实际 HTML：每页一个标题、一个 canonical、无重复描述；文章 JSON-LD 能解析且与正文一致。将站点地图提交到搜索平台，并通过平台报告确认实际收录情况。

## 升级

主题设置保存在 Halo 的 ConfigMap 中，升级不会丢失配置。在后台 → 外观 → 主题中找到「绿野 Luye」→ 升级 → 上传新版本 zip 即可；也可卸载旧版后重新安装（卸载前需先切换到其他主题）。已发布版本的制品不作修改，修复问题一律发新版本。

- **1.1.1**：修复首页「精选专题」区文章封面不显示。根因为模板层：卡片用 `spec.cover` 筛选文章却从未输出该字段，只渲染装饰叶子图；同时 `.featured-cover img` 为无类名通配选择器，会将区内所有图片压缩为右上角 40px 水印。修复后封面以 `object-fit:cover` 铺满卡片，原有渐变底保留作为兜底——文章无封面或封面地址失效时均不会塌陷。已在 Halo 2.26.0 真机环境验证：有封面正常渲染、清空封面后该文自动跳过、封面 404 时渐变底透出且高度不变；首页、归档、文章、分类、标签等全路径及移动端单列布局均正常。
- **1.1.0**：首页信息层次升级——新增 Hero 数据徽章行（文章/分类/标签自动统计，琥珀色 `#E8B96E` 暖色点缀）、「精选专题」区（自动取最近 3 篇带封面的文章）、双列网格文章布局（可在设置中切回经典纵向列表）、首页作者卡片，导航栏支持搜索入口（需填写搜索页链接）。全部新模块均可通过主题设置开关或改写文案。

## 故障排查

- **设置不生效**：主题设置页点击「重载主题配置」。
- **字体加载慢或样式异常**：主题设置 → 外观 → 关闭「加载在线衬线字体」，自动回退系统字体（宋体/苹方）。
- **天气特效不显示**：确认主题设置 → 外观 → 「启用天气背景特效」已开启；切换按钮在导航栏右侧；用户的选择保存在浏览器本地，重新点击可关闭。
- **评论区不显示**：需安装并启用评论插件，且文章/页面开启了评论；未安装评论插件时评论区自动隐藏。
- **安装后页面报错**：确认 Halo 版本 ≥ 2.26.0，本主题使用了 2.26.0 引入的 `layout.html` 页面布局契约。
- **其他问题**：请携带 Halo 版本与报错截图提交 Issue：https://github.com/ReganQing/Luye/issues
